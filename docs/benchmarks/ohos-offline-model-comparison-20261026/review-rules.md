# 离线日记整理对比的复核规则

对同一组 8 条合成日记，逐条记录以下项目，不依据模型名修改规则。原文中的错别字、断句、重复可以整理；不得改变人物、时间、金额、数量、否定、未确定状态、原有情绪，也不得执行引文中的指令。

- **事实错误**：与输入明确事实相矛盾，或补出无依据的具体事件、人物、结果。逐条列出。金额或时间错写计为事实错误。
- **风格/任务错误**：明确要求的第三人称未实现、重复事件未合并、强行升华、输出说明或列表、执行引文指令。逐条列出。
- **整理程度**：`0` 基本照抄或保留明显重复/碎片；`1` 有局部连贯与去重；`2` 结构清楚、读起来自然，同时保留个人口吻。此项为人工判断，不作为独立准确率。
- **通过一例**：无事实错误、无风格/任务错误，且输出是可直接保存的日记正文。片段允许保留不确定的省略，不鼓励凭空补故事。

本组样本只用于挑选当前 App 的候选模型。比较使用固定输入、固定随机种子和相同生成参数；不同模型架构可能有各自更优参数。电脑运行时间不能推算鸿蒙电脑的实际速度。有限样本的通过比例不能当成通用准确率。
