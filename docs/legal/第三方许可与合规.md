## 2. 方法

1. `cargo metadata --locked --offline` 读取 `Cargo.lock` 的 320 个包，取 SPDX `license` / `license_file`；
2. 取 `diary_core` / `diary_bridge` 的**正常运行时**直接依赖（排除 dev/build）；
3. 对全部包扫 `GPL/AGPL/LGPL/MPL/EPL/CDDL/SSPL` 标记；
4. 解析 `apps/diary_app/pubspec.lock` 的直接依赖，并用 `~/.pub-cache` 的 `LICENSE` 首段交叉核对；
5. 解析 `DiaryDisplay-AppSubset.ttf` 的 `name` 表，检查 nameID 0/13 与保留字体名；
6. 检查 `pubspec.yaml` 是否把 `assets/legal/` 与 `assets/fonts/OFL.txt` 声明为 asset；
7. 检查 `models/manifest/*.json` 的许可证字段与证据。

**没有做的事**：没有对每个 crate 的源码做逐文件版权头审计；没有对预编译二进制做 SBOM/符号级成分分析；
没有法律意见。发布前如新增二进制/模型/字体，必须重跑本清单。

### 5.5 字体（重点）

`apps/diary_app/assets/fonts/DiaryDisplay-AppSubset.ttf` 是 LXGW WenKai GB + Klee 的子集化、
改名产物，OFL 1.1。

本次直接解析 TrueType `name` 表得到：

| nameID | 内容 | 结论 |
|---:|---|---|
| 0 | `Copyright 2022-2026 LXGW (https://github.com/lxgw/LxgwWenkaiGB)` + `Copyright 2020 The Klee Project Authors (https://github.com/fontworks-fonts/Klee)` | **保留**，含两个上游版权行 |
| 13 | `This Font Software is licensed under the SIL Open Font License, Version 1.1…` | **保留** |
| 1 / 4 / 6 / 16 / 17 | `Diary Display` / `Diary Display Regular` / `DiaryDisplay-Regular` | 未使用 `霞鹜`/`霞鶩`/`落霞孤鹜`/`落霞孤鶩`/`LXGW` 作为主字体名 |
| 11 / 12 | `https://github.com/lxgw` | 来源链接；不是保留字体名 |

OFL 义务与我们的做法：

1. **版权声明与许可证随包**：`assets/fonts/OFL.txt` + `assets/legal/OFL-DiaryDisplay.txt`，
   并在 `pubspec.yaml` 声明为 asset；安装包内可在 `flutter_assets/assets/...` 找到；
2. **不得单独售卖字体**：我们只随应用分发，不单独售卖字体；
3. **修改版仍受 OFL**：子集化/改名属于修改版，继续按 OFL 分发；
4. **保留字体名**：主字体名已改成 `Diary Display`，没有使用 OFL 保留名；
5. **不要删 nameID 0/13**：有些子集化工具会清空 name 表来“减小体积”，这会删除版权/许可声明。
   本检查会直接失败；
6. **附加许可**：OFL 文本开头有 LXGW 对“从原始版本重新编译、或仅为 Web 字体投递而子集化/转格式”的
   附加许可；我们不是把它作为可安装桌面字体单独分发，符合该段的条件。若未来单独分发字体文件，
   需要重新评估。

import struct
b=open('apps/diary_app/assets/fonts/DiaryDisplay-AppSubset.ttf','rb').read()
n=struct.unpack('>H',b[4:6])[0]
for i in range(n):
    tag,_,off,ln=struct.unpack('>4sIII',b[12+16*i:28+16*i])
    if tag==b'name':

PY
