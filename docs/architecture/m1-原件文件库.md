# M1 · 原件文件库与导入交接（B1b）

对应 issue [#21](https://github.com/xingxue-ux/unwritten-diary/issues/21) · 日期 2026-09-27 · 执行人 xingxue-ux

代码在 `crates/diary_core/`（`src/assets.rs`、schema v2）。记录这一片定下来的决定与没做到的部分。

## 定下的决定

| 决定 | 理由 |
|---|---|
| **文件先落定、再写数据库** | 文件系统与 SQLite 不是一个事务。先把字节搬进内容存储，再在一个事务里写 blob / asset / source / 导入日志。中途失败最多留下一个没人引用的 blob 文件，**不会**出现「数据库里有资产、磁盘上没有文件」 |
| **不信任调用方给的哈希** | `finish` 自己流式重算 sha256 与字节数，和声明比对；对不上报 `integrity_failed`。平台层给的数字只能当线索，不能当事实 |
| 内容按 sha256 去重 | 存放为 `blobs/<sha 前两位>/<sha>`。导入相同内容只存一份，但两条导入记录的时间、来源、原始文件名仍各自独立（契约 3.2 节） |
| 新增 `integrity_failed` 错误码 | 契约第 7 节原本没有「复制过来的字节不完整」这个状态。按流程先改契约文档与 Dart 枚举，再改实现 |
| 失败时**保留**暂存文件 | 不能悄悄丢掉用户刚给的材料。会话标成 `error` 并带 `error_code`，用户可重试或取消 |
| 重开资料库把未完成的导入标成 `recoverable` | 不猜「复制完了没有」。调用方拿 `imports.status` 看到真实状态，再决定重试 `finish` 还是 `cancel` |
| 取消 = 删暂存文件 + 删会话记录 | 契约的导入状态枚举里没有「已取消」。取消后 `imports.status` 返回 `not_found`，语义清楚 |
| 租约是内存态 + 10 分钟有效期 | 句柄不该跨进程残留；过期租约在下次 `assets.open` 时清掉 |
| 文件不见时把库里状态改成 `missing` | 「库里有记录、盘上没文件」必须让用户看见，不能糊过去 |

## 验证到了什么

`cargo test -p diary_core` 共 30 项（12 项文件库 + 16 项记录 + 2 项单测）。值得点名的：

- **删掉外部原文件，资料库里的那份仍能打开**（E07）：导入后删除外部来源文件，`open_asset` 读出的字节与导入前一致。
- **篡改被拒**：声明哈希与核心自己算的不一致 → `integrity_failed`，会话标 `error`，暂存文件保留，**没有产生资产**。
- **内容去重**：同一份字节导入两次 → 两条资产记录，底层存储只占一份（`asset_stats` 的字节数等于单份大小）。
- **中断可恢复**：写了一半没 `finish` 就关库，重开后会话是 `recoverable` 而不是 `ready`；暂存文件还在，可以直接重试完成。
- **失败互不影响**（E08）：取消一个导入，另一个照常完成。
- **文件真丢了会如实报告**：人为删除文件库里的文件后，`open_asset` 报 `asset_missing`，并把库里的状态改成 `missing`。
- **大文件不占内存**（E09 的内存部分）：导入 **64 MiB** 文件，进程峰值常驻内存从 5.9 MiB 到 5.9 MiB（**+0.0 MiB**），证明是按 64 KiB 缓冲流式处理的。

## 没有做到的

- **孤儿 blob 不清理**：进程死在「文件已搬进内容存储、事务尚未提交」之间，会留下一个没人引用的 blob 文件。它按内容寻址、不影响正确性，后续导入相同内容会复用它。B7 的永久清理只删**被清理记录引用**的 blob（且最后一个引用者消失时才删），不会扫掉这种没有 `assets` 行的孤儿；孤儿清理仍没有入口。
- **没有引用计数**：现在没有删除资产的接口，所以还不存在「删一条引用误删共享原件」的风险。等有了删除，必须同时把引用计数做上（契约 3.2 节已写明这条约束）。
- **不是真的满盘**：文件写入的 ENOSPC 只做了错误码映射，没有造真实满盘环境（记录那一片用的是 SQLite 页数上限，走的是同一条 `SQLITE_FULL` 路径）。
- **权限变化没验证**：`PERMISSION_DENIED` 的映射写了，没有真的改目录权限去测。
- **媒体属性没填**：`media_duration_ms` / `width` / `height` 三列留空，要等提取那一片去读。
- **桥接没接线**：`crates/diary_bridge` 还没暴露这些方法，前端暂时调不到。
