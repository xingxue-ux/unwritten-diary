# 鸿蒙 UI 对齐与验收

2026-10-22。对齐基线为 GitHub `main` 的 `2b5cdc6`，Windows 实现位于
[`experience_shell.dart`](../../apps/diary_app/lib/src/experience_shell.dart) 与
[`sketch_ui.dart`](../../apps/diary_app/lib/src/sketch_ui.dart)。

本次直接替换现有鸿蒙应用的 ArkUI 产品页面与公共样式，沿用原有入口和应用身份。
原有 Store、C ABI、资料库与录音生命周期保持原接口；
后端探针不会作为 UI 对齐的验收证据。

插件、完整备份/恢复、封面设置等尚未提供产品页面的能力，在界面中继续如实说明。

## 自动检查

```sh
python tools/check_ui_parity.py
python tools/test_check_ui_parity.py
python tools/check_ohos_visual.py
python tools/test_check_ohos_visual.py
python tools/check_arkts_capi_contract.py
python tools/check_arkts_scope.py --require-tsc
python tools/check_docs.py --require-yaml
```

`check_ohos_visual.py` 比较两端实际颜色、字体及许可文件、断点，检查产品页面有没有重新引入
系统色、圆角或遗漏共享按钮样式，检查风格与阅读导出是否仍落到占位页。其 13 项自测包括
颜色漂移、缺字体、错字体、缺许可、漏按钮样式、系统色泄漏、断点漂移、占位页回归，
以及真机暴露的百分比叠加边框、API 23 属性包装器调用绘制方法、低对比度前景色回归等反例。
已接入 GitHub Actions 的 `docs` job。

这些检查只证明源码和资源约束，不能证明屏幕上的最终效果。
`check_arkts_scope.py` 排除 ArkUI DSL，不能代替 HAP 编译。
