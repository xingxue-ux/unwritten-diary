# 鸿蒙电脑纯离线版

分支：`codex/ohos-offline-llm`。应用版本：`1.0.5`（`1000005`），应用标识仍为
`com.lingxing.unwrittendiary`，设备类型为鸿蒙电脑 `2in1`。

本分支鸿蒙发布包的安装名称及商店名称均为“不写日记demo”。发布签名包已上传华为后台，
安装包合法性校验已达标；这不代表上架审核已通过。发布包校验记录见
[离线体验版发布记录](../benchmarks/ohos-demo-release-20261027.json)。

此版本随包提供 Qwen3.5-4B Q4_K_M，用于文本日记整理；SenseVoice INT8 用于语音转写，
BGE Small Chinese 用于本地语义检索。所有模型首次启动时从安装包流式复制到应用沙箱并校验
SHA-256，无需下载模型、设置服务地址、配置账号或填写密钥。模型运行文件合计
3,004,756,957 字节，安装包和沙箱各保存一份，首次准备时需要相应的可用存储空间。

## 离线边界

- 鸿蒙模块不声明 `ohos.permission.INTERNET`，仅保留录音和后台录音所需权限。
- `diary_capi` 与 `diary_core` 使用 `offline-only` 特性，禁用远程适配器注册，并在 HTTP
  传输入口解析地址、建立连接之前拒绝请求。即使恢复的资料库含有旧在线服务配置，也不能使用它联网。
- 首次准备自动创建并选中内置本机整理服务，关闭其他生成服务的启用状态；不读取或请求在线密钥。
- 文本生成在应用进程中调用 llama.cpp，不启动 HTTP 服务、外部进程或下载助手。
- 发布模块只导出产品入口。历史联网探针、下载探针不在模块 Ability 清单和产品入口引用链中。
- 用户原始记录不因整理而改写，生成正文作为独立日记版本保存，并显示人工智能生成提示。

## 模型和推理

Qwen3.5 权重来源、固定版本、文件大小与 SHA-256 见
[`qwen3.5-4b-q4_k_m.json`](../../models/manifest/qwen3.5-4b-q4_k_m.json)。
此处仅使用文本生成权重，不包含图片理解功能所需的视觉投影模型。

llama.cpp 固定版本为 `71255fefc092b0344f2acddb891388814ae961be`，提供通用 ARM64 与
支持点积/半精度指令的两个库，按设备能力选择。Qwen3.5 按官方关闭思考的聊天模板拼接空思考块，
不把思考内容当成日记正文。CPU 使用 4 个线程，输出上限 2048 token，单次计算超时为 300 秒。

离线版使用精简产品指令，保留冻结模板、写作偏好和原始材料边界。写作设置在材料数据段结束后再次
明确，改善小模型忽略人称的情况；金额、否定、未确定事项和原有情绪不得改写。提示词审计版本分别为
`ohos-qwen35-1`、`ohos-qwen35-organize-1`。长材料仍按原有两步计划处理并保留来源关联。

## 构建

构建机器需提前准备依赖和三个清单中指定的模型。应用使用时不需要联网。

```bash
# 在仓库根目录；三个源目录应已含固定清单对应的文件。
python3 tools/stage_ohos_models.py \
  --asr-dir /path/to/sense-voice-int8 \
  --bge-dir /path/to/bge-small-zh-v1.5-ours \
  --llm-dir /path/to/qwen3.5-4b

# 原生库，包含离线 Rust 核心、NAPI 桥接及两个 LLM CPU 库。
apps/ohos-diary-core/scripts/build-native.sh

# 在有完整鸿蒙 SDK、hvigor 和签名材料的环境构建。
SKIP_NATIVE=1 BUILD_MODE=release apps/ohos-diary-core/scripts/build-hap.sh
```

模型许可证、NOTICE 和全部运行文件清单随包提供。权重、运行库、签名资料与大型构建产物不提交 Git。

## 2026-10-26 验证范围

- 核心单元测试：118 通过，1 个需独立真实语义模型的测试按既有要求跳过。
- 离线策略测试 2 项、离线日记提示词及资料边界测试 10 项通过。
- 模型打包清单测试 6 项、首次部署与配置保留测试 10 项通过。
- 鸿蒙交互回归 31 项通过，覆盖风格切换、录音、搜索、日程及离线模型检查的失败重试，
  并验证搜索内容就地准备、取消后不重启旧查询和准备失败反馈。
- 非界面 ArkTS 35 个文件语法与作用域检查通过；鸿蒙 debug、release 均实际构建成功。
- 文档链接、界面结构、字体资源与 ArkTS/C ABI 接口契约检查通过。
- 在电脑 WSL 中编译当前产品的原生推理桥，再通过真正的离线核心，从 8 个全新合成资料库运行
  创建记录、提交、冻结风格、排队生成、持久保存整条链路。没有预先连接测试，没有密钥，使用
  `PanicTransport` 确认没有网络传输；8 次生成成功，原文均保持不变。
- 逐例复核中，退款否定、数字、未确定事项和复杂情绪保留；重复开会句得到合并，第三人称设置
  得到执行。部分较长、原本连贯的记录仍改写较少，单次生成也可能不充分分段，不能把这组样本
  当成所有文本和风格的质量保证。
- 原有量化对比及完整样本见
  [模型对比报告](../benchmarks/ohos-offline-model-comparison-20261026/README.md)；
  新提示词通过实际离线核心生成的原始结果见
  [离线核心回归记录](../benchmarks/ohos-qwen35-offline-app-20261026.json)。

已在 HarmonyOS 电脑 HAD-W32（API 23、ARM64、32 GB 内存）实际安装测试，覆盖首次模型准备、
本机整理检查、文字保存与日记生成、混合搜索、风格保存和录音转写。
首次模型检查耗时 3.697 秒；105 字合成记录的一次日记生成耗时 18.744 秒。
这些是单台设备的单次结果，不能代表所有输入、设备或功耗表现。
录音到本机转写的链路已跑通，但现场声学条件不足以评估识别准确率。
真机生成也可能略微加强原文语气，部分风格执行仍需更多样本验证。

测试中修复了三个界面问题：搜索准备需跳转后再点一次、录音完成后仍显示历史排队状态、
已有日记仍提示等待整理。详细结果见[真机验证记录](../benchmarks/ohos-qwen35-device-20261026.md)。

安装前已完整备份原应用资料，测试在隔离资料库运行。覆盖安装后再次核对原资料文件未变；
正常启动离线版会自动选择本机整理，并保留历史记录与原服务配置。
