# 鸿蒙界面文案检查（2026-10-24）

本轮检查鸿蒙应用的全部页面及提示生成代码，将系统文案改为简洁中文，移除面向开发者的诊断信息。用户记录原文不作替换。

## 展示规则

- 提示只说明结果和下一步，不展示接口名、错误码、内部编号、原始服务响应、运行库文件名或完整路径。
- 错误按错误码映射为中文；不从英文报错中猜原因，未知错误使用通用提示。原错误码和重试属性保持不变。
- 状态枚举有中文映射，新增未知状态不会直接显示英文。
- 服务预设和常见模型使用中文名称。预设地址、模型标识和模型位置收在主动编辑区，正常操作不显示这些配置细节。
- 日记、摘录和用户填写的内容保持原样，包括其中的英文。系统文件选择器中的实际文件信息不作篡改。
- 永久删除仍区分删除与保留的内容，保留确认操作和不可恢复说明，不展示内部版本编号。

## 主要修订

| 场景 | 修订后 |
| --- | --- |
| 语音转写 | 显示“可以使用”“检查转写功能”“检查通过，可以开始录音”；隐藏模型路径和检查结果原文 |
| 模型服务 | 中文预设、模型名称和访问密钥说明；原始连接报告不直接上屏 |
| 连接失败 | 显示“访问密钥无效”“请检查或更换密钥”；刷新服务状态后仍保留具体原因 |
| 录音 | 仅保留录音、保存、中断和恢复的必要说明；移除片段登记、最终化和内部错误信息 |
| 日记 | 当前、候选和处理结果使用中文，不展示版本编号；等待配置时不再保留“正在整理”提示 |
| 任务 | 类型、状态和失败原因均为中文；隐藏任务编号、调度字段和内部优先级 |
| 搜索 | 使用简短的内容覆盖提示，不展示核心警告原文；保留关键词和语义检索 |
| 导出 | 使用“保留排版”“纯文本”；结果不展示导出路径和内部保存标记 |
| 回收站 | 使用简短的删除预览与保留说明，隐藏记录和版本编号 |
| 本地功能 | 保留模型和搜索准备状态，移除原生库、配置文件和接口能力清单 |

## 验证

- 对 16 个页面、5 个状态容器和 4 个共用展示文件进行文案扫描与人工复核，共 25 个文件；未发现残留的英文系统文案。
- 10 组交互回归通过。新增检查覆盖外部英文报错和内部路径不进入提示、未知状态的中文兜底、导出结果不回显路径；新增连接失败原因刷新后保留、等待状态清除处理中提示的回归。
- 35 个非界面 ArkTS 文件检查通过，debug/release 完整页面编译与签名打包通过。
- HAD-W32 / API 23 真机在隔离资料库中检查记录、日记、搜索、片段、个人页、转写、模型服务、任务详情、确认框、风格设置、整理设置、导出和回收站的可见文案。
- 真机检查覆盖空白状态、输入校验、草稿保存、收好记录、等待配置、转写检查成功、关键词和语义检索、无效密钥失败。含英文的虚构记录原文保持不变。
- 无效密钥测试使用无效字符串，不使用真实凭据；连接测试只发送测试文字。没有向远程服务发送日记。
- 四个随包本地模型的大小、哈希和存储方式核对通过，六个原生库齐全；签名证书与原应用相同。

本轮不重新申请麦克风权限、不进行长时间录音，也不使用真实密钥重跑计费生成。业务主流程的上一轮结果见 [首次使用验收](鸿蒙首次使用验收-20261024.md)。回收站有内容时的删除分类和日记候选分支完成源码检查；本轮未在真机执行永久删除或计费生成。
