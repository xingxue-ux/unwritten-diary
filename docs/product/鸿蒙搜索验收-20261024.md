# 鸿蒙搜索检查与修复（2026-10-24）

本轮检查关键词、语义与混合搜索的请求生命周期、分页、结果展示，以及资料变化后的刷新。搜索引擎接口和用户原文不变。

## 修复

- 清空或修改查询会使旧请求失效；迟到结果不会回显，并会关闭其检索会话。空白输入也不会留下正在搜索的状态。
- 首次请求尚未返回会话编号时即可取消；取消立即停止界面等待，已加载的多页结果保留，停止加载与没有结果分别说明。
- 分页成功后清除旧错误；游标或会话过期时重新发起查询，使用新的结果集与游标。混合升级的自动重试只允许一次，持续失败会明确提示。
- 同一记录的原文同时命中记录和文字来源时合并展示，命中原因合并；分页重复的同一命中不再追加。不同记录、不同实际来源或不同摘录仍保留。
- 混合检索仍在等待语义结果时显示处理中，不提前显示没有结果或没有更多。
- 新记录、索引整理和资料变动会刷新当前搜索与索引状态。隐藏页不在后台重跑搜索，并清除过时摘要；返回搜索页后重搜。已取消的结果在资料变化后也会清除。
- 索引状态请求有顺序保护，较晚返回的旧状态不会覆盖新状态。

## 验证

- 改动前通过回归用例复现取消、清空查询、分页错误残留、过期游标和原文重复展示问题；修复后 26 组 ArkTS 控制器交互检查通过。
- Rust 搜索与语义索引检查：110 项通过，2 项既有手动检查跳过（十万片段性能量测、宿主真模型量测）。本轮没有修改核心搜索算法。
- debug/release 完整编译通过；四个随包模型与六个原生库核对通过，发布包签名证书与原应用一致。
- HAD-W32 真机使用独立资料库，通过真实界面创建 13 条虚构记录，验证同一原文去重、分页遍历完整记录、正确打开原记录、取消保留结果、清空输入、空白校验和回车搜索。
- 使用随包模型准备语义索引；返回搜索页后就绪提示自动刷新，近义描述在语义与混合模式下均实际命中。再新增一条相同原文的独立记录，回到搜索页后自动从一条更新为两条，证明不会误合并不同记录。

请求延迟、分页失败重试、会话过期和取消竞态由确定性的控制器回归覆盖，不用真实网络或用户资料制造故障。

本轮测试共使用 14 条虚构记录，不配置远程模型服务。隔离资料在验收后清理，最终发布包覆盖安装；正式资料库和原有配置保留。
