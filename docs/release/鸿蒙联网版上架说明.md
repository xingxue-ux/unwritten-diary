# 不写日记 · 鸿蒙联网发布版

名称：不写日记。版本：1.0.7（1000007）。包名：`com.lingxing.unwrittendiary`。
设备范围仅鸿蒙电脑（2in1），保留原联网版交互、风格、录音与搜索功能。
按用户确认，本鸿蒙发布包暂不提供内容导出：移除入口和路由，工作线程拒绝导出请求，其他平台不受影响。

## 模型及网络用途

本版日记整理仅通过深度求索官方 HTTPS 接口调用第三方大模型，不自建、训练或部署生成式大模型。
原生传输层在 DNS/连接前拒绝其他模型地址，不跟随重定向；Windows 不受这一鸿蒙限制影响。
模型列表直接查询官方服务，显示真实模型名称。应用不内置开发者或公共访问密钥，
用户自行填写密钥并启用在线服务。服务方可能收取模型调用费用。

第三方官方公示：<https://cdn.deepseek.com/policies/zh-CN/model-algorithm-disclosure.html>。
公示名称 Deepseek Chat，生成式人工智能服务备案号 `Beijing-DeepseekChat-202404280016`，
服务提供者算法备案号为网信算备330105747635301240017号。
这是第三方服务的备案信息，不是本应用的 APP 备案号，不作免备案声明。

启用在线整理后，待整理的文字、录音转写及写作偏好发送至深度求索，用于生成日记；
原始记录保留在本机。语音转写与语义检索使用随包本地模型，不上传录音。
应用声明联网权限，不能按不联网应用填报。

## 首次使用及审核备注

首次启动在模型准备和产品页加载之前展示在线整理与隐私说明，拒绝会退出，确认后记住选择。
完整说明及第三方备案信息可在“我的 > 隐私与模型服务说明”中离线查看。
人工智能生成的正文在阅读页及版本预览中显示显式标识，原文保留。

建议审核备注：

> 本版仅支持鸿蒙电脑。日记整理通过深度求索官方接口调用已备案第三方模型，
> 不自建或训练生成式大模型。首次启动展示服务来源及数据发送说明，
> “我的”中提供完整隐私和第三方备案公示。使用在线整理需自行填写服务密钥，
> 检查连接只发送测试文字；未配置仍可记录、使用本机转写和搜索。
> 语音及检索模型随包提供，不含本地 LLM。日记结果已标注人工智能生成，原文保留。
