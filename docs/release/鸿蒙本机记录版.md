# 不写日记 1.0.8：本机记录版

分支 `codex/ohos-no-llm-release`，从联网发布版 `7c6d482` 独立创建。
这里移除的是生成式整理；本机语音转写和语义搜索按用户确认保留，不能把本版描述为“完全不使用 AI”。

## 功能范围

- 保留现有界面、文字记录、录音、本机转写、关键词/语义/混合搜索及回收站。
- 移除日记生成、模型服务、写作风格、自动整理计划入口及对应路由。
- 日记页按天回看原始记录，仍可阅读旧版本已经保存的历史正文，不新增生成内容。
- 应用名称仍为“不写日记”，版本 1.0.8（1000008），仅鸿蒙电脑。
- 首次说明和应用内隐私说明改为本机处理；不申请 INTERNET 权限。
- 沿用本次鸿蒙发布包不提供内容导出的设置。

## 调用边界

不仅移除界面：鸿蒙原生核心在冻结快照和排队之前拒绝生成请求；自动计划不排生成任务，
任务驱动取消旧版遗留的待执行生成/回应任务，保留原始记录、历史正文和其他本地任务。
原生 HTTP 传输层在 DNS/连接之前拒绝所有在线模型请求。C ABI 不再宣告生成、风格和在线模型接口能力。

`release_policy::GENERATION_ENABLED` 在鸿蒙目标恒为 false。其他目标默认保留原行为；
`no-generation` Cargo feature 只用于在宿主机复现同一边界并测试。
本机转写和语义检索模型、引擎和部署流程保持原有版本，首次启动不再修复或切换在线服务。

## 验证命令

```sh
OHOS_TYPESCRIPT_PATH=/path/to/typescript node tools/test_ohos_no_generation.cjs
OHOS_TYPESCRIPT_PATH=/path/to/typescript node tools/test_ohos_bundled_models.cjs
OHOS_TYPESCRIPT_PATH=/path/to/typescript node tools/test_ohos_interactions.cjs
python tools/check_arkts_scope.py --require-tsc
cargo test -p diary_core --features no-generation --test no_generation_test
cargo test -p diary_capi --features no-generation no_generation_release_rejects_generation_but_advertises_local_processing
```

完整鸿蒙编译沿用 `apps/ohos-diary-core/scripts/build-native.sh` 和 `build-hap.sh`。
必须重新编译本分支原生核心，不能复用联网版的 `libdiary_capi.so`。本机模型准备方式不变。

本分支用于另备发布方案。应用市场资料、隐私政策链接及截图应与实际版本同步；
生成式功能移除不等于其他上架要求自动满足。当前代码修改不替换已提交的 1.0.7 申请。
