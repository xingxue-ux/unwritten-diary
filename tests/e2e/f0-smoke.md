# Flutter 交互演示验收步骤

Windows x64 与 Android arm64 应分别验证，记录设备、系统版本、Flutter 版本、构建模式与结果。尚未运行的设备不能算通过。

1. 冷启动直接进入「记录」页，不必先配置模型。资料库打开期间显示小猫写字动画；「我的 → 封面与加载动画」可重复预览。
2. 检查手机底部导航和电脑顶栏；「记录、日记、搜索、片段、我的」均可打开。320 px 窄窗和系统字体放大时，输入和提交按钮仍可滚动到达。
3. 输入中文，Enter 换行或确认输入法候选，不提交；Windows Ctrl+Enter 可提交。等待自动保存确认；失败时文字不清空，「重试」仍可点。
4. 点「收好这一刻」，到「片段」找到刚写的文字；「搜索」输入其中的词，等待约 250 毫秒后查看结果并打开详情。
5. 「添加材料」可选择演示照片/文件/视频卡片，单项可移除；「录音」可演示开始、暂停、继续、结束，但页面始终说明没有真实采集音频。
6. 「日记」查看自然段正文、来源、版本候选和主动回应。触发模拟重新整理后，当前版仍稳定；用户主动采用候选后才变更。
7. 「我的」依次进入风格、模型、整理时机、任务、插件、备份、存储与回收站。密钥输入禁用；备份按钮不得产生或声称产生真实备份。

本清单验证交互与页面状态，不验证真实持久化、录音、文件导入、语义检索、模型生成、备份恢复或 Android 真机能力。
